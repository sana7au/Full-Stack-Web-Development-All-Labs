DEMO SEQUENCE (fresh Node server):
  1. Student, requested 10 => HTTP 200; allowedRows=3; credits=7.
  2. Teacher, requested 10 => HTTP 200; allowedRows=10; credits=29.
  3. Wrong key => HTTP 401, no SQL query, no credit deduction.
  4. Search Ali as Student => matches limited to 3; next student credit=6.
  5. Send six more student requests => credits=0; next gets 429.
  6. Optional 403: student.allowedTables = []; restart Node; select Student.

NOTES:
  - Real row count depends on available customers4 records.
  - Credits are in Node memory, not saved to MySQL.
  - The page's steps summarize the HTTP result; they are not live backend timings.
  - Files contain no CREATE/UPDATE/DELETE SQL statements.
